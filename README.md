# Aether build machine

Builds the Aether apps on GitHub's machines. The source code is not here: each build fetches it from a
private repository with a read-only key, compiles it and deletes it.

Install Aether: [macOS](https://github.com/vansh7266/homebrew-aether#readme) ·
[Windows](https://github.com/vansh7266/scoop-aether#readme)
